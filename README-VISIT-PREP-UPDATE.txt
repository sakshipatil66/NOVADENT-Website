NOVADENT Storytelling Plus — Visit Prep Update

New feature:
- Interactive Visit Preparation Checklist on the Home page.
- Four optional prep items, live completion count and progress bar.
- Reset checklist and direct link to the appointment page.
- Keyboard focus styling and reduced-motion support.
- Responsive mobile layout.

Setup:
1. Extract this ZIP.
2. Open PowerShell in the folder containing package.json.
3. Run: npm install
4. Run: npm run dev

Note: The checklist runs in the browser only and does not save patient information or medical data. Build/browser testing was not run in this environment because dependencies are not installed here.
