NOVADENT STORYTELLING WEBSITE — SETUP

IMPORTANT: package.json is in this folder. Open PowerShell in the folder where package.json is located.

Windows PowerShell:
  npm install
  npm run dev

Open the local URL printed by Vite (usually http://localhost:5173).

Production build check:
  npm run build

This project keeps the existing React/Vite app and its routes/features. The homepage already contains a chapter-style story flow, reveal-on-scroll behavior and chapter navigation. The storytelling polish adds a subtle reading progress indicator and chapter styling.
